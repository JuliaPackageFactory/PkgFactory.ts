# Contributing to {{{PKG}}}.jl

Thank you for your interest. Contributions by people and by AI coding agents are welcome.

## Issues

Bug reports and feature requests go to [GitHub Issues](https://github.com/{{{OWNER}}}/{{{PKG}}}.jl/issues).
The issue forms ask for a minimal reproducer and your Julia environment; please fill them in, since they
are what a maintainer or an agent needs to start. Open an issue before starting significant changes.

## Development

[AGENTS.md](AGENTS.md) is the single source for how to work in this repository: the commands to run,
the definition of done, the rules, and the code conventions. It applies to everyone, not only to agents.
The [ColPrac](https://github.com/SciML/ColPrac) guidelines apply to collaboration.

## Pull Requests

Work on a branch and open a pull request against `main`. The pull request template asks what changed,
why, and how you validated it; every check in AGENTS.md's definition of done must pass before review.
